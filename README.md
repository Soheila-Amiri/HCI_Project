# Project Summary
Collecto is an image-based application inspired by social media platforms like Instagram, enhanced with a search engine for image content. Users can search for images using text input or voice commands and explore results in a social-media-style feed.</br></br>
Collecto extends traditional collections by allowing users to search across all collections or within a specific collection, using image descriptions. Descriptions are either provided by users at upload time or automatically generated using Azure image captioning, ensuring full searchability.</br></br>
The application supports both manual and voice-based interactions for searching and content management.
